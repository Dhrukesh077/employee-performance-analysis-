Employee performance analysis is a practical application of statistics where organizations evaluate employee productivity, performance, salary distribution, working hours, project completion, and promotion trends. # 📈 Descriptive Statistics

Descriptive Statistics summarize and describe the main characteristics of a dataset. Instead of examining every individual observation, descriptive statistics provide concise numerical measures that represent the entire dataset.

Descriptive statistics are generally divided into two categories:

- Measures of Central Tendency
- Measures of Dispersion

These measures help answer questions such as:

- What is the average employee salary?
- What is the most common salary?
- How much variation exists in employee performance?
- Are employee salaries consistent?

---

# 📍 Mean

The Mean is the arithmetic average of all observations.

It provides a single value that represents the center of the dataset.

### Formula

\[
\bar{x}=\frac{\sum x}{n}
\]

### Applications

- Average Salary
- Average Age
- Average Performance Score
- Average Working Hours

### Python

```python
df["Salary"].mean()
```

---

# 📍 Median

The Median is the middle value after arranging observations in ascending order.

Unlike the mean, the median is not affected by extreme values.

### Applications

- Salary Analysis
- Income Distribution
- Employee Performance

### Python

```python
df["Salary"].median()
```

---

# 📍 Mode

Mode is the value that appears most frequently.

It is especially useful for categorical data.

### Applications

- Most Common Department
- Most Frequent Salary
- Most Common Promotion Status

### Python

```python
df["Salary"].mode()
```

---

# 📍 Range

Range measures the spread of data.

### Formula

```
Range = Maximum − Minimum
```

### Applications

- Salary Spread
- Age Distribution
- Performance Comparison

### Python

```python
df["Salary"].max() - df["Salary"].min()
```

---

# 📍 Variance

Variance measures how far observations are spread around the mean.

Large variance indicates highly dispersed data.

### Formula

\[
\sigma^2=\frac{\sum(x-\bar{x})^2}{n}
\]

### Python

```python
df["Salary"].var()
```

---

# 📍 Standard Deviation

Standard Deviation is the square root of variance.

It is one of the most important measures in statistics.

### Formula

\[
\sigma=\sqrt{\sigma^2}
\]

### Python

```python
df["Salary"].std()
```

---

# 🎲 Probability

Probability measures the likelihood of an event occurring.

Probability values always lie between **0** and **1**.

| Probability | Meaning |
|-------------|----------|
| 0 | Impossible Event |
| 1 | Certain Event |
| 0.5 | Equal Chance |

### Formula

\[
P(A)=\frac{\text{Favourable Outcomes}}
{\text{Total Outcomes}}
\]

### Example

Probability that an employee gets promoted.

### Python

```python
(df["Promotion_Status"]=="Yes").mean()
```

---

# 🎯 Conditional Probability

Conditional Probability measures the probability of an event under a specific condition.

Example:

"What is the probability of promotion if Performance Score is greater than 80?"

### Formula

\[
P(A|B)=
\frac{P(A\cap B)}
{P(B)}
\]

### Python

```python
high=df[df["Performance_Score"]>80]

(high["Promotion_Status"]=="Yes").mean()
```

---

# 📖 Bayes' Theorem

Bayes' Theorem updates probabilities after considering new information.

It is one of the foundations of Artificial Intelligence and Machine Learning.

### Formula

\[
P(A|B)=
\frac{P(B|A)P(A)}
{P(B)}
\]

### Applications

- Medical Diagnosis
- Spam Detection
- Fraud Detection
- AI Systems
- Recommendation Systems

---

# 📉 Skewness

Skewness measures the symmetry of data.

| Value | Interpretation |
|--------|----------------|
| Positive | Right Skewed |
| Negative | Left Skewed |
| Zero | Symmetrical |

Python

```python
from scipy.stats import skew

skew(df["Salary"])
```

---

# 📊 Kurtosis

Kurtosis measures the peakedness of data.

| Type | Description |
|------|-------------|
| Mesokurtic | Normal Peak |
| Leptokurtic | Sharp Peak |
| Platykurtic | Flat Peak |

Python

```python
from scipy.stats import kurtosis

kurtosis(df["Salary"])
```

# 🧠 Principal Component Analysis (PCA)

Principal Component Analysis (PCA) is a dimensionality reduction technique used to simplify datasets while preserving maximum information.

Instead of working with many correlated variables, PCA transforms them into a smaller set of independent components called **Principal Components**.

### Advantages

- Reduces Complexity
- Removes Redundant Information
- Improves Machine Learning Performance
- Faster Computation
- Better Visualization

Python

```python
from sklearn.decomposition import PCA

pca=PCA(n_components=2)
```

# 📊 Exploratory Data Analysis (EDA)

Exploratory Data Analysis (EDA) is the first and one of the most important stages of any data analysis project. It involves examining, summarizing, and visualizing datasets to understand their structure, identify patterns, detect anomalies, and prepare the data for further statistical analysis.

Rather than immediately applying statistical formulas or machine learning algorithms, analysts first explore the dataset to gain insights into its characteristics. EDA helps answer questions such as:

- Is the dataset complete?
- Are there any missing values?
- Are there duplicate records?
- What is the distribution of numerical variables?
- Which variables are categorical?
- Are there any outliers?
- Are the variables correlated?

A well-executed EDA process improves the quality of analysis and ensures that conclusions drawn from the data are accurate and reliable.

---

# 🎯 Objectives of EDA

The primary objectives of Exploratory Data Analysis are:

- Understand the dataset structure.
- Identify missing values and duplicates.
- Examine data types.
- Summarize numerical variables.
- Analyze categorical variables.
- Detect outliers.
- Understand data distributions.
- Explore relationships between variables.
- Prepare the dataset for statistical analysis and machine learning.

# 📍 Measure of Central Tendency

Measures of Central Tendency describe the center or typical value of a dataset.

The three most commonly used measures are:

- Mean
- Median
- Mode

These measures help answer questions such as:

- What is the average employee salary?
- What salary represents the middle employee?
- Which salary occurs most frequently?

---

# 📊 Mean

## Definition

The **Mean** is the arithmetic average of all observations.

It is calculated by adding every value and dividing the result by the total number of observations.

### Formula

\[
\bar{x}=\frac{\sum x}{n}
\]

---

## Python Implementation

```python
mean_salary = df["Salary"].mean()

print(mean_salary)
```

Example Output

```text
56420.75
```

---

## Interpretation

The average monthly salary of employees is **₹56,420.75**.

This means that if the salaries of all employees were distributed equally, every employee would receive approximately this amount.

---

## Applications

- Average salary analysis
- Employee compensation
- Budget planning
- Payroll analysis

---

# 📊 Median

## Definition

The **Median** is the middle observation after arranging all values in ascending order.

If the number of observations is even, the median is the average of the two middle values.

Unlike the mean, the median is not affected by extreme values.

---

## Python Implementation

```python
median_salary = df["Salary"].median()

print(median_salary)
```

Example Output

```text
55500
```

---

## Interpretation

Half of the employees earn less than ₹55,500, while the remaining half earn more than ₹55,500.

---

## Applications

- Salary comparison
- Income analysis
- Outlier-resistant analysis

---

# 🧠 Bayes' Theorem

Bayes' Theorem updates the probability of an event after incorporating new information.

It is widely used in:

- Artificial Intelligence
- Medical Diagnosis
- Fraud Detection
- Spam Filtering
- Recommendation Systems

### Formula

\[
P(A|B)=
\frac{P(B|A)\times P(A)}
{P(B)}
\]

Where:

- **P(A)** = Prior Probability
- **P(B)** = Probability of Evidence
- **P(B|A)** = Likelihood
- **P(A|B)** = Posterior Probability

---

# 🐍 Bayes' Theorem Example

Suppose:

- Probability of Promotion = 0.42
- Probability of High Performance = 0.51
- Probability of High Performance given Promotion = 0.87

Then:

```python
P_A = 0.42

P_B = 0.51

P_B_given_A = 0.87

P_A_given_B = (
P_B_given_A*P_A
)/P_B

print(P_A_given_B)
```

Example Output

```text
0.716
```

Interpretation:

There is approximately a **71.6% probability** that an employee has been promoted given that they are a high performer.

# 🔔 Normal Distribution

The **Normal Distribution**, also known as the **Gaussian Distribution**, is the most important probability distribution in statistics.

Many natural phenomena follow this distribution, including:

- Human Height
- IQ Scores
- Employee Salaries
- Examination Marks
- Blood Pressure
- Manufacturing Measurements

---

# ⭐ Characteristics of Normal Distribution

- Bell-shaped curve
- Perfectly symmetrical
- Mean = Median = Mode
- Highest frequency occurs near the center
- Tails extend infinitely in both directions
- Total probability equals 1

---

# 📐 Probability Density Function

The mathematical equation of the Normal Distribution is:

\[
f(x)=\frac{1}{\sigma\sqrt{2\pi}}
e^{-\frac{(x-\mu)^2}{2\sigma^2}}
\]

Where:

- μ = Mean
- σ = Standard Deviation
- x = Observation

---

# 🐍 Python Example

```python

std = df["Salary"].std()

)

plt.title("Gaussian Distribution")

plt.show()
```

# 📊 What is PCA?

Principal Component Analysis (PCA) is an unsupervised machine learning technique used to reduce the number of variables while preserving maximum information from the original dataset.

Instead of analyzing many correlated features, PCA transforms them into a smaller number of uncorrelated variables called **Principal Components**.

These components capture most of the variability in the dataset.

---

# 🌟 Why PCA?

Large datasets often contain:

- Highly correlated variables.
- Redundant information.
- High computational cost.
- Difficult visualization.

PCA solves these problems by:

- Reducing dimensions.
- Eliminating redundancy.
- Improving computational efficiency.
- Simplifying visualization.
- Preserving maximum variance.

# 📐 Angle Between Two Vectors

The angle between vectors measures how closely they point in the same direction.

### Formula

\[
\theta
=
\cos^{-1}
\left(
\frac{A \cdot B}
{||A||\,||B||}
\right)
\]

---

# 🐍 Python Code

```python
angle = np.arccos(

np.dot(A,B)

/

(

np.linalg.norm(A)

*

np.linalg.norm(B)

)

)

print(angle)
```

Interpretation:

- Small angle → Strong similarity.
- Large angle → Weak similarity.
